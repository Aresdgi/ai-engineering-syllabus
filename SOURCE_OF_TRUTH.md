# Source of Truth

## Fuente única

La única fuente de contenido educativo de la plataforma es:

`4GeeksAcademy/ai-engineering-syllabus`

URL:

`https://github.com/4GeeksAcademy/ai-engineering-syllabus`

Branch inicial:

`main`

## Qué significa "íntegramente basado en el repo"

Todo elemento presentado como contenido del curso debe poder responder:

1. ¿De qué archivo del repo procede?
2. ¿De qué commit procede?
3. ¿Qué fragmento o estructura original representa?
4. ¿Ha sido modificado?

Si no se puede responder, no puede presentarse como contenido oficial del curso.

## Datos que deben provenir del repositorio

Obligatoriamente:

- títulos;
- descripciones;
- orden de proyectos;
- milestones educativos;
- instrucciones;
- requisitos;
- entregables;
- criterios de evaluación;
- contextos;
- empresas ficticias;
- datasets;
- assets;
- lecciones;
- enlaces;
- tecnologías mencionadas;
- restricciones técnicas;
- material en español/inglés;
- relaciones entre proyectos cuando estén expresadas en el repo.

## No permitido

La plataforma no debe inventar:

- un módulo llamado de una manera que 4Geeks no use;
- una lección intermedia para "rellenar";
- requisitos adicionales;
- proyectos complementarios presentados como oficiales;
- una rúbrica propia que sustituya la del repo;
- una secuencia distinta presentada como secuencia oficial;
- objetivos educativos no sustentados por la fuente;
- resúmenes que alteren requisitos.

## UI vs contenido

Es correcto crear:

- "Continuar aprendiendo";
- "% completado";
- "Mis notas";
- "Favoritos";
- "Buscar";
- "Abrir proyecto";
- "Preguntar al tutor".

Eso es interfaz.

No es correcto crear contenido educativo nuevo debajo de esas pantallas y presentarlo como parte del syllabus.

## Versionado

Cada importación debe registrar:

- repo;
- branch/ref;
- commit SHA;
- fecha;
- path;
- blob SHA o hash local.

La plataforma debe poder indicar qué versión del syllabus está mostrando.
